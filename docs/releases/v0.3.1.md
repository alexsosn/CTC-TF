# Ugarit Context Parsing v0.3.1

This release adds an all-lanes, read-only researcher query API to the existing Burns Workbooks **feature-only** module for the exact reviewed Copenhagen Ugaritic Corpus (CUC). It supersedes v0.3.0 without changing the underlying Burns/CUC alignment policy or Text-Fabric warp.

## Researcher-facing change

A query of only `burns_category_1` undercounts overlapping annotations because independently sourced occurrences may start at the same CUC word. The new public `ugarit_context_parsing.research_queries.iter_burns_occurrences(api, category=None, semantic_status=None)` enumerates every numbered occurrence lane, reconstructs canonical CUC word spans from existing `burns_span_N` edges, and preserves overlapping occurrences, Burns source categories, semantic statuses, annotation provenance, and match rules. It rejects malformed/incomplete lanes and a base-only Text-Fabric load rather than returning a misleading count. Existing findspot-only modules with no exact lexical records legitimately yield zero matches.

On pinned real source acceptance, **45 Workbooks** yield 10,419 normalized annotations, of which **7,402** are exact lexical occurrences on **5,909** carrier words, up to six lanes on one carrier. This is the count of exactly aligned textual occurrences, **not** a count of unique deities, lemmas, annotations, or all ambiguous/unmatched references.

## Install, materialize, and query

Install this release from its immutable tag after publication, using Python 3.10+ and Text-Fabric >=13.1,<14. Supply your own permitted Burns Workbooks and an exactly reviewed CUC checkout. The primary CLI is unchanged:

```sh
python -m pip install 'git+https://github.com/alexsosn/CTC-TF.git@v0.3.1'
ugarit-context-parsing module /path/to/local/Workbooks \
  --input-format pdf --cuc /path/to/cuc/tf/0.2.8 \
  --output /new/absent/path/burns-module
```

The output is a feature-only CUC module: no `otype.tf`, no `oslots.tf`, no replacement `otext.tf`, and no Burns-created nodes. It is a user-local derivative, **not** bundled with the software. Load the base and module in order:

```python
from tf.fabric import Fabric
from ugarit_context_parsing.research_queries import iter_burns_occurrences

api = Fabric(
    locations=['/path/to/cuc/tf/0.2.8', '/new/absent/path/burns-module'],
    modules=[''], silent='deep',
).loadAll(silent='deep')
assert api is not None

all_exact = tuple(iter_burns_occurrences(api))
print(len(all_exact))
for hit in iter_burns_occurrences(api, category='divine_name'):
    print(hit.occurrence_id, hit.span_nodes, hit.semantic_status)
```

The `burns_headword_N` string is a source grouping label, **not** a certified lemma or divine entity. `homograph_excluded`, `no_secure_cultic`, and `unsupported` statuses remain queryable and are never silently counted as positive deity mentions. Filter by semantic status to answer narrower questions. Failed/ambiguous lexical mappings remain in the local report. See [researcher query documentation](../feature-only-module.md#researcher-api-query-all-exact-occurrences-not-just-lane-1).

## Compatibility and provenance

- Exact CUC base: `DT-UCPH/cuc@ad69400f5446e1c8217af01659c7c10ab00c015b`, `tf/0.2.8`.
- The module remains compatible with the Context-Fabric / cfabric-mcp reader when loaded over the same reviewed base.
- `module-v1` explicitly retains the older JSON-feature module as a rollback path. The former standalone row-slot converter and extended-warp entity experiment are not part of this release.
- `agora.materializer.json` declares the parent-bound, local-only `cuc-burns-csv` producer, implemented by `ugarit_context_parsing.agora_adapter`. The Agora sandbox expects a **pre-created empty** output staging directory, whereas the direct CLI expects an absent destination. Host validation is pinned to the reviewed Agora **Bubblewrap** sandbox host.
- Agora registry registration and the GitHub Release/tag are **separate distribution actions**. This software package **does not by itself register** the producer in Agora. Managed host installation needs its own separately reviewed registry pin.

## Rights and source-quality limits

Burns's thesis and Workbooks remain subject to **CC BY-NC-ND 2.5**. The software is MIT-licensed. Users must obtain and retain their own authorized original inputs. Exactly aligned lexical records must not be conflated with the 1,841 resolved-line nonmatches or 276 ambiguous-span occurrences: neither class becomes asserted word-level TF features. The local alignment report may contain source-derived material and must not be redistributed. **No Burns-derived data files are attached to the release.**

## Publication and validation gate

The new `.github/workflows/publish-reviewed-v0.3.1.yml` workflow is **manual-only**, requiring explicit owner confirmation `v0.3.1@<full-merge-sha>` at the current `master` commit. Its release gate resolves the exact associated merged squash PR and verifies the independent PR-head tree, all six required PR-head integration workflows, successful master-push tests, version consistency and immutable release notes, then refuses any existing conflicting tag or release. It publishes no restricted source data.

The v0.3.0 GitHub Release, tag, and its prior two-parent-merge verification remain unchanged. Publication does not automatically update downstream Agora registry pins or users' local modules.
