## First isolated projection schema (not yet an installable artifact)

- `burns_in_<category>` is an integer `1` on each word in an **exact** lexical alignment of that category, absent elsewhere. Phrase membership is not the same as attributing a phrase headword to each token.
- `burns_headword` and `burns_root` are *scalar, single-word-only* and emitted only when all applicable exact single-word occurrences agree on the value. If there are divergent values, **omit the scalar** and return a deterministic per-node collision manifest for sidecar/reporting. Do not replace a missing scalar with an arbitrary candidate or a serialized list.
- The helper does not claim to offer individual occurrence IDs as TF nodes. Those require a derived graph or different representation. Do not expose the helper as a resolved #68 module before the full integration gates.
- Findspots are excluded from the first isolated code slice pending a real local KTU/fragment conflict audit; the final module must provide tablet-level features only for unambiguous observational values, otherwise sidecar/conflict fields and no misleading value.

Stop and leave PR draft if native search tests cannot run, real local source audit is missing, overlapping-label information would be discarded, emitter changes violate exact reviewed CUC identity, output ownership may delete foreign files, or a newly added feature is unqueryable without JSON parsing. Do not merge a PR merely because isolated unit tests pass. Keep release issue #16 blocked until the final v2 contract is actually demonstrated.
